to check version
- npx playwright --version

to execute test
- npx playwright test
- npx playwright test 'file name' 'file name' [to run specific file]


to show report
- npx playwright show-report

by default execute in headless mode, to run in headed mode
- npx playwright test --headed

by default run on three browsers
- npx playwright test 'file name' --project=browser name [chromium / firefox / webkit]

to run a specific test
- npx playwright test -g 'testing' [testing is the word the method name contains]

to run on UI mode
- npx playwright test --ui

to perform debug using code execution
- npx playwright test 'file name' --debug
